# Дипломный проект. Часть 3: Автотесты для UI веб-приложения Stellar Burgers

Проект содержит автоматизированные UI-тесты для веб-приложения **Stellar Burgers**. 
Тесты написаны на **Python** с использованием библиотеки **Selenium WebDriver**, фреймворка **Pytest** и паттерна проектирования **Page Object Model (POM)**. Реализовано построение отчетов с помощью **Allure**.

---

## 🛠 Технологический стек

* **Язык**: Python 3.x
* **Фреймворк тестирования**: Pytest
* **Инструмент автоматизации UI**: Selenium WebDriver
* **Менеджер драйверов**: WebDriver Manager (для автоматического скачивания Chrome/Firefox)
* **Отчетность**: Allure Framework
* **HTTP-запросы**: Requests (для подготовки тестовых данных и API-авторизации)

## 🚀 Инструкция по запуску

### 1. Подготовка окружения и установка зависимостей
Склонируйте репозиторий и перейдите в корневую папку проекта. Создайте виртуальное окружение и установите пакеты:

```bash
# Создание виртуального окружения
python -m venv venv

# Активация (для Windows)
venv\Scripts\activate

# Активация (для macOS/Linux)
source venv/bin/activate

# Установка необходимых библиотек
pip install -r requirements.txt
```

### 2. Запуск тестов
Тесты автоматически параметризованы для кроссбраузерного запуска в **Google Chrome** и **Mozilla Firefox**.

```bash
# Запуск всех тестов с сохранением результатов для Allure
pytest --alluredir=allure-results
```

### 3. Просмотр отчета Allure
Для генерации локального сервера с красивым отчетом выполните *(требуется установленный утилитный пакет Allure CLI на компьютере)*:

```bash
allure serve allure-results
```
